🔧 FIX THE 400 REGISTRATION ERROR
==========================================

PROBLEM: Frontend is trying to connect to http://localhost:3001 (doesn't exist in production)

SOLUTION: Add VITE_API_URL environment variable to Netlify

==========================================
STEP-BY-STEP INSTRUCTIONS
==========================================

1. Go to: https://app.netlify.com/sites/dragfolio/configuration/env

2. Click: "Add a variable" → "Add a single variable"

3. Enter:
   Key:    VITE_API_URL
   Value:  https://drag-folio-five.vercel.app
   Scopes: All (or Production)

4. Click: "Create variable"

5. Go to: https://app.netlify.com/sites/dragfolio/deploys

6. Click: "Trigger deploy" → "Deploy site"

7. Wait 2-3 minutes for build to complete

8. Test: https://dragfolio.netlify.app/register

==========================================
VERIFICATION
==========================================

After deployment, open https://dragfolio.netlify.app in your browser:

1. Press F12 to open Developer Console
2. Look for this message in console:
   "Using API URL from environment: https://drag-folio-five.vercel.app"

3. If you see "Using API URL: /api" instead, the env variable isn't set correctly
