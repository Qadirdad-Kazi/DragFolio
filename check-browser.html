🔧 Commands to Run in Browser Console

Open https://dragfolio.netlify.app, press F12, and paste these:

1. Check what API URL your app is using:

// This will show what API URL the frontend thinks it should use
console.log('Current Window:', window.location.origin);
console.log('Checking API calls in Network tab...');

// Watch the network tab while you try to register
// Look for the URL of the failed request

2. Test the backend directly:

fetch('https://drag-folio-five.vercel.app/health')
  .then(r => r.json())
  .then(d => console.log('Backend health:', d));

3. Test registration directly:

fetch('https://drag-folio-five.vercel.app/api/auth/register', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    email: `test${Date.now()}@example.com`,
    password: 'Test123!@#',
    name: 'Test User'
  })
})
.then(r => r.json())
.then(d => console.log('Registration result:', d))
.catch(e => console.error('Error:', e));
